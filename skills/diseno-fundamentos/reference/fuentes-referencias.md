# Fuentes de referencias reales

Las referencias se buscan **antes** de construir; no se inventa la dirección visual
(inventarla produce el «look IA» genérico). Cada fuente sirve para una
pregunta concreta. Se abre la que toca y se capturan 2-3 ejemplos (1440×900 y móvil).

| Pregunta | Fuente | Para qué sirve |
|---|---|---|
| ¿Qué se está haciendo ahora? (volumen) | httpster.net | Mucha web real, poco filtrada |
| Filtrar por estilo, sector o tipo | curated.design | Colección con filtros |
| Algo raro o experimental | hoverstat.es | Webs de autor, interacción poco común |
| Una sola sección (hero, precios, pie…) | unsection.com | Comparar la misma pieza en muchas webs |
| Un flujo (alta, checkout, onboarding) | pageflows.com | Flujos grabados de producto, no páginas sueltas |
| Llamadas a la acción | cta.gallery | Solo secciones CTA |
| Microinteracción o motion de app | 60fps.design | Detalles animados de apps reales |
| Guardar lo encontrado | cosmos.so | Tablero visual de referencias |
| Premiadas (registro marca, inmersivo) | awwwards.com (SOTY/SOTD) | Listón alto de craft e inmersión |

Herramientas, no referencias: **uicolors.app** (genera escalas Tailwind a partir de un
color de marca; se contrasta después con [color.md](color.md)) y **glass3d.dev** (generador
de CSS «glass» 3D; úsalo solo si el registro lo pide, porque el glass es un tell de IA si
va sin motivo).
